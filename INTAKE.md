# **Cahier des charges fonctionnel — Coach de drague et messages**

## **1. Présentation du projet**

### **1.1. Concept**

**Coach de drague et messages** est une application mobile basée sur l'intelligence artificielle qui accompagne les utilisateurs dans leurs échanges romantiques.

L'application permet de démarrer une conversation, de répondre à un message reçu, de flirter avec respect

### **1.2. Positionnement**

L'application se positionne comme un **assistant de communication romantique**, et non comme un outil de manipulation.

Elle aide les utilisateurs à trouver les bons mots, à communiquer naturellement, à développer leur confiance et à respecter le consentement.

### **1.3. Identité du produit**

| Élément        | Description                                                |
| -------------- | ---------------------------------------------------------- |
| Nom provisoire | Coach de drague et messages                                |
| Noms possibles | Flirt Coach, Spark Messages, Rizz Coach, Charme IA         |
| Type           | Application mobile avec IA                                 |
| Public cible   | Adultes de 18 ans et plus                                  |
| Ton            | Confiance, humour, séduction respectueuse, coaching social |
| Monétisation   | Freemium, abonnements, crédits et publicités optionnelles  |

### **1.4. Limites du positionnement**

L'application ne doit pas :

- Promettre de faire tomber une personne amoureuse.
- Encourager la manipulation émotionnelle.
- Générer du contenu sexuel explicite.
- Imiter une personne réelle sans son accord.

## **2. Fonctionnalités de l'application**

### **2.1. Génération de messages**

L'utilisateur peut demander à l'IA de générer des messages adaptés à différentes situations.

**Possibilités :**

- Démarrer une conversation.
- Répondre à un message reçu.
- Flirter de manière naturelle.
- Relancer une conversation.
- Préparer un message avant un rendez-vous.
- Formuler des excuses.
- Rédiger un message de rupture douce.

### **2.2. Réponse à une capture d'écran**

L'utilisateur peut transmettre une capture d'écran d'une conversation.

L'IA analyse le contenu et génère **3 propositions de réponse** adaptées au contexte.

Cette fonctionnalité fait partie des fonctionnalités Premium et peut également être accessible avec des crédits.

### **2.3. Styles de messages**

L'application propose différents tons pour adapter les messages.

| Styles de base                        | Styles avancés    |
| ------------------------------------- | ----------------- |
| Tons de base accessibles gratuitement | Drôle             |
|                                       | Romantique        |
|                                       | Mystérieux        |
|                                       | Direct            |
|                                       | Élégant           |
|                                       | Provocateur léger |

Les styles avancés sont accessibles avec Premium.


### **2.4. Analyse de conversation**

L'utilisateur peut faire analyser une conversation par l'IA.

L'analyse permet de :

- Évaluer si la conversation progresse.
- Conseiller la prochaine étape.
- Proposer un rendez-vous lorsque le contexte s'y prête.

### **2.5. Banque de messages**

L'application propose une banque de messages pour différentes situations :

- Messages d'ouverture.
- Messages de relance.
- Messages pour un rendez-vous.
- Messages d'excuses.
- Messages de rupture douce.

### **2.6. Mode « Respect »**

Ce mode permet de détecter les messages susceptibles d'être :

- Trop insistants.
- Excessivement sexualisés.
- Manipulateurs.

L'IA propose alors une alternative plus saine et respectueuse.

### **2.7. Historique**

Les utilisateurs Premium peuvent accéder à l'historique de leurs messages générés.

## **3. Modèle économique**

L'application repose sur un modèle **Freemium + Abonnements + Crédits**.

Les publicités constituent une source complémentaire de revenus, et non le modèle économique principal.

### **3.1. Offres et abonnements**

| Offre                | Prix indicatif        | Avantages                                                                          |
| -------------------- | --------------------- | ---------------------------------------------------------------------------------- |
| Gratuit              | 0 €                   | 3 à 5 générations par jour, tons de base, publicités optionnelles                  |
| Premium hebdomadaire | 4,99 à 6,99 €/semaine | Quota élevé ou messages illimités, tous les styles, réponses à une capture d'écran |
| Premium mensuel      | 9,99 à 14,99 €/mois   | Historique, coaching de profil, analyses de conversation                           |
| Premium annuel       | 39,99 à 59,99 €/an    | Meilleur tarif mensuel, accès prioritaire, nouvelles fonctionnalités               |

### **3.2. Système de crédits**

Le système de crédits permet aux utilisateurs d'accéder à des générations sans souscrire obligatoirement à un abonnement.

**Fonctionnement :**

- 1 crédit = 1 message généré.
- Chaque utilisateur gratuit reçoit 5 crédits par jour.
- Des packs de 20, 50 ou 100 crédits sont disponibles à l'achat.
- Une analyse de capture d'écran coûte 2 crédits.

Les prix des packs de crédits restent à définir.

### **3.3. Publicités**

Les publicités sont destinées uniquement aux utilisateurs gratuits.

**Formats prévus :**

- Bannières discrètes en bas de l'écran.
- Vidéos récompensées permettant de recevoir 2 crédits supplémentaires.

**Restrictions :**

- Aucune publicité pour les abonnés Premium.
- Pas de publicité plein écran intrusive au lancement.
- Pas de publicité impossible à fermer.
- Pas de publicité promouvant des contenus pour adultes ou des sites de rencontre.

## **4. Parcours utilisateur**

Le parcours principal est organisé autour de la génération de réponses à une conversation.

1. **Ouverture de l'application**

   L'utilisateur voit le message : « Colle son dernier message. »
2. **Génération gratuite**

   L'IA propose 3 réponses adaptées au message reçu.
3. **Personnalisation**

   L'utilisateur souhaite obtenir une réponse plus audacieuse, drôle ou personnalisée.
4. **Proposition Premium**

   L'application affiche : « Débloque les 3 styles supplémentaires avec Premium. »
5. **Choix de monétisation**

   L'utilisateur peut regarder une publicité récompensée ou souscrire un abonnement.
6. **Proposition annuelle**

   Après 3 jours, l'application propose l'abonnement annuel avec une remise.

## **6. Priorités de monétisation**

Les sources de revenus sont classées dans l'ordre suivant :

1. **Abonnement hebdomadaire :** source principale de revenus, adaptée à une utilisation ponctuelle liée à une conversation en cours.
2. **Packs de crédits :** alternative pour les utilisateurs qui ne souhaitent pas souscrire un abonnement.
3. **Publicités récompensées :** possibilité d'obtenir des crédits supplémentaires gratuitement.
4. **Bannières publicitaires :** source de revenus secondaire, uniquement si elles ne dégradent pas l'expérience utilisateur.

## **7. Protection, confidentialité et éthique**

### **7.1. Restriction d'âge**

L'application est réservée aux adultes de 18 ans et plus.

Une case de confirmation « J'ai 18 ans ou plus » doit être prévue.

### **7.2. Modération des contenus**

L'application doit interdire la génération de messages :

- Haineux.
- Harcelants.
- Sexuellement explicites.
- Destinés à manipuler une autre personne.

### **7.3. Confidentialité**

Les captures d'écran des conversations ne doivent pas être conservées plus longtemps que nécessaire.

L'application doit expliquer clairement l'utilisation des données des utilisateurs.

### **7.4. Transparence**

Les utilisateurs doivent être informés que les réponses de l'IA sont des suggestions et ne garantissent aucun résultat.

### **7.5. Signalement**

Un bouton **« Signaler un contenu »** doit permettre de signaler un message problématique.

Une politique de confidentialité doit également être disponible.
